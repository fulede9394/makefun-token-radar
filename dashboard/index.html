Token Launch Radar

200 protocols that record no token, ranked by what a launch would be worth — snapshot 2026-11-14, DefiLlama.

How the ranking works

Implied value = TVL × 0.35 × growth × tenure. Growth comes from the 7-day TVL change (clamped to −40%…+120%, halved, so a fast grower is worth up to 1.6× and a fast shrinker down to 0.8×; no change reported counts as flat). Tenure is how long the protocol has run with no token recorded, up to 4 years, worth up to 1.4×. The board only ranks protocols that record no token and are not a bridge, a centralised exchange, a liquid-staking product or a versioned deployment of something else — the snapshot's watchlist rule, applied to all 342 protocols that record no token. Every row says "records no token", never that it has none: DefiLlama's record is not proof, and a launch is never promised.
